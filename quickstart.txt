OCCS CLI quick start
====================

Standalone installation
-----------------------
Install Node.js/npm, download the current OCCS CLI release ZIP and extract it.
Open a terminal in the extracted folder containing package.json, then run:

  npm install
  npm link
  occs --version
  occs --help

See README.md for operating-system prerequisites and installation details.
Native ATool bundles already contain Node.js, OCCS CLI and npm dependencies;
skip standalone installation when using that bundled runtime. A custom ATool
CLI Path overrides its bundle, and installed bundles do not update themselves.

Browser SSO (OCCS CLI 1.4.0 or later)
------------------------------------
Install Chrome, Edge or Chromium separately, then run:

  occs login --sso --customer CUSTOMER --region REGION --tenancy non-prod --session sso

Complete the browser login, including QR code and phone/passkey approval.
The CLI closes the browser, verifies API access, and saves encrypted Comms
session cookies. A HAR file is not needed. Select a browser with
--browser-executable PATH or OCCS_SSO_BROWSER when automatic detection fails.
The sign-in timeout is five minutes; --sso-timeout accepts milliseconds.

Read and preview using the saved alias:

  occs list-configs --session sso --json
  occs preview --session sso --package MY_PACKAGE --input ./input.json --render-type PDF --output ./preview.pdf

Use a known working package/input pair. To sign in again after expiry:

  occs login --sso --session sso

Commands do not open the browser or repeat SSO login automatically. Other
commands reuse the saved current session when no explicit selector is supplied.

Password login remains available:

  occs login --username USERNAME --customer CUSTOMER --region REGION --tenancy non-prod --session password-session

Enter the password when prompted or supply existing environment defaults.
Oracle-hosted XML conversion requires a password session. SSO preview can use
JSON or local --xsd XML conversion. Migration from an SSO source requires an
explicit source bearer token; its session cookies are not a replacement.

ATool
-----
The updated Qt source exposes Settings -> Sign In to Comms (SSO)... and uses
the selected alias for normal Comms operations. Both the updated ATool UI and
OCCS CLI 1.4.0+ are required. Updating only the CLI does not add the action to
an older app. ATool's real phone/browser sign-in still needs live validation;
the CLI login, reads, ConfigId creation and PDF preview have been verified.
See README.md and the ATool user guide for remaining limitations.

Keep ~/.occs-session.json and ~/.occs-cli/credential-key private. Do not place
HAR files, session cookies, keys or customer inputs in source control.
